# Local assets

The files in this directory are stored locally so the application UI does not
depend on a CDN or GitHub at runtime.

## `vendor/leaflet/`

- `leaflet.css`: Leaflet 1.9.4 stylesheet
- `leaflet.js`: Leaflet 1.9.4 JavaScript
- `LICENSE`: Leaflet license

Source: <https://leafletjs.com/>

## `images/`

- `marker-icon-2x-green.png`: current-location marker
- `marker-icon-2x-red.png`: place-search marker
- `marker-shadow.png`: shared marker shadow

The colored marker images were obtained from:
<https://github.com/pointhi/leaflet-color-markers>

The shadow image is from the Leaflet 1.9.4 distribution.
